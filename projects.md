## Project 1: Opticrop — Smart Agricultural Crop Health & Yield Optimization
- **Repository:** [https://github.com/Charan-19DB/Opticrop](https://github.com/Charan-19DB/Opticrop)
- **Problem:** Smallholder farmers frequently suffer significant crop yield loss due to late detection of plant leaf diseases, suboptimal soil nutrient management, and erratic weather fluctuations without access to agricultural experts.
- **Solution:** Engineered an AI-driven agricultural decision-support application that leverages deep learning computer vision to diagnose crop diseases from leaf photographs, predict suitable fertilizer treatments, and forecast yield potential.
- **Technologies:** Python, Deep Learning, OpenCV, Flask / FastAPI, Computer Vision, Git & GitHub.
- **My contribution:** Built the computer vision classification pipeline for leaf disease detection, integrated image preprocessing with OpenCV, and developed the backend prediction API.
- **Possible improvement:** Deploy a lightweight edge-compatible model (TensorFlow Lite) for real-time offline mobile inference in rural areas with low network bandwidth.

## Project 2: CogniVision — Intelligent Computer Vision & Cognitive Perception Platform
- **Repository:** [https://github.com/Charan-19DB/CogniVision](https://github.com/Charan-19DB/CogniVision)
- **Problem:** Automated visual monitoring in surveillance and industrial environments often struggles with inaccurate multi-object tracking, high latency, and false positive detections in challenging lighting conditions.
- **Solution:** Developed an end-to-end computer vision and cognitive analytics system capable of real-time object detection, spatial tracking, and visual event classification.
- **Technologies:** Python, Deep Learning (YOLO / CNN architectures), OpenCV, NumPy, REST APIs, Git.
- **My contribution:** Designed the spatial object tracking pipeline, implemented video stream frame-by-frame inference, and optimized detection thresholds for real-time performance.
- **Possible improvement:** Introduce multi-camera spatial re-identification and automated anomaly alert notifications via WebSockets.

## Project 3: SmartAid — Intelligent Emergency & Healthcare Assistance System
- **Repository:** [https://github.com/Charan-19DB/SmartAid](https://github.com/Charan-19DB/SmartAid)
- **Problem:** During medical emergencies and first-response situations, panic and lack of immediate medical guidance or rapid emergency triage lead to critical delays in patient care.
- **Solution:** Created an intuitive emergency response and first-aid advisory platform that provides guided first-aid assistance, symptom checking, and emergency service locator routing.
- **Technologies:** Python, Machine Learning, Web Technologies (HTML5, CSS3, JavaScript), REST APIs, Git.
- **My contribution:** Designed the triage logic algorithm, built the conversational first-aid assistant interface, and integrated emergency contact geolocation services.
- **Possible improvement:** Integrate automated voice assistance and speech-to-text input for hands-free operation during critical emergencies.
