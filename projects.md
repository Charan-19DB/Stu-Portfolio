## Project 1: Smart Student Attendance & Performance Tracking System
- **Problem:** Conventional attendance logging using paper sheets is slow, prone to proxy attendance, and requires laborious manual data entry to calculate monthly percentages and identify students below mandatory attendance thresholds.
- **Solution:** Designed and developed a modular Java-based desktop application that streamlines attendance recording, tracks student attendance records using formatted CSV datasets, and automatically generates real-time eligibility warnings for end-semester examinations.
- **Technologies:** Java (OOP principles, File I/O), CSV Data Parsing, Swing GUI components, Git & GitHub.
- **My contribution:** Designed the entire backend logic for student record management, implemented file persistence using CSV streams, and developed the attendance threshold calculation engine.
- **Possible improvement:** Integrate a SQLite database backend for relational data integrity and build a web-accessible REST API dashboard.

## Project 3: Library Book Inventory & Borrowing Manager
- **Problem:** Departmental library book tracking is frequently plagued by misplaced books, overdue borrowing periods, and lack of immediate stock visibility for students and faculty.
- **Solution:** Implemented a console-based and GUI-ready inventory system that enables librarian administrators to add, search, issue, and return books while keeping real-time stock counts.
- **Technologies:** Python 3, Object-Oriented Programming, JSON file storage.
- **My contribution:** Authored the data structures (dictionaries and classes) to manage book catalogue status, search filters, and borrowing timestamps.
- **Possible improvement:** Integrate email notification reminders for overdue book returns using automated background tasks.
